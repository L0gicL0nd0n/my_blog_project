Testing Examples

Using cURL:

# Get all articles
curl http://localhost:5000/api/articles

# Create article
curl -X POST http://localhost:5000/api/articles \
    -H "Content-Type: application/json" \
    -d '{"title":"Test","content":"API test"}'

# Update article
curl -X PUT http://localhost:5000/api/articles/1 \
    -H "Content-Type: application/json" \
    -d '{"title":"Updated Title"}'

Using Python:

import requests

# Get articles
response = requests.get('http://localhost:5000/api/articles')
print(response.json())

# Create article
new_article = {
    'title': 'Python Test',
    'content': 'Created via Python'
}
response = requests.post('http://localhost:5000/api/articles', json=new_article)
print(response.json())
